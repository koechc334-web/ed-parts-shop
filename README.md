
# Ikokituftii.co.ke — Kenya's Open Marketplace

Live: https://ed-parts-shop.onrender.com

I started this to enable upcoming sellers increase their audiences in Eldoret.

Started as ed-parts-shop for car parts, but sellers in Langas and CBD kept asking for phones, clothes, farm produce, etc. So I made it an open market — anything can be listed.

Stack: Flask + SQLite + vanilla JS (no React, keep it light for Safaricom data)

Features:
- M-Pesa STK push
- Boda delivery: CBD 200, Langas/Nas 350, Elgon View 400
- Low stock alert for shop owners
- etc category because sellers kept asking "where do I list?"

How to run:
pip install -r requirements.txt
python app.py
